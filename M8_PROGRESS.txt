Key fixes landed this session:
  - ReportB4JMeasure: platform split. B4A measures with
    android.graphics.Paint (Typeface.create(family, style), metrics from
    Paint.FontMetrics fields; Android ascent is negative so it is negated).
    AWT code remains the B4J branch. Text widths measured at BaseSize 1000
    and scaled linearly, same as B4J.
  - IsFamilyAvailable: Android has a fixed builtin family set (sans-serif,
    serif, monospace, cursive, condensed...); unknown families fall back to
    the platform default with a W-MEA-001 substitution warning, same
    contract as the B4J Dialog fallback.
  - ResolveList default family: sans-serif on B4A, Dialog on B4J.
  - ReportDataExporter / ReportHtmlExporter: fixed the B4A path split
    (the filename was derived from the already-trimmed directory, causing
    ENOENT); ExportCsv/ExportJson/ExportXml/ExportHtml now write correctly.
  - ReportDocxExporter / ReportXlsxExporter: zip helper invoked via
    jo.Initialize(Me) instead of reflecting the hardcoded
    b4j.example package; XLSX now carries its own zipFolder helper.
  - ReportPdfExporter: B4A guarded (diagnostic + False) so the suite can
    run without PDFBox.
  - Tests: |relative|ReportEngineTests now resolves each platform's own
    copy (tests/B4A and tests/B4J); the root tests\ReportEngineTests.bas
    copy is the legacy original. Font checks parameterised (serif vs
    Arial) and golden/PDF subs skipped per platform.
  - B4A test app Main runs the suite on launch, copies bundled fixtures
    (Files/fixtures/...) from assets to internal storage, and writes
    fixture-check.txt.
